# 12 - Notes and resources library

**What to build:** The notes, slides and resources that already exist against a batch become browsable in one place, so a student can revise without asking an instructor for files.

Download is permitted where the owner has allowed it, and refused where they have not.

**Blocked by:** None - can start immediately

**Status:** ready-for-agent

- [ ] A student can browse every resource on a batch they are enrolled in, grouped usefully
- [ ] A student who is not enrolled cannot reach the library at all
- [ ] A resource marked downloadable can be downloaded
- [ ] A resource not marked downloadable can be viewed but not downloaded
- [ ] A resource scheduled to publish later is invisible until then
