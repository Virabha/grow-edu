# 30 - Test performance report

**What to build:** A corporate admin can see how their students performed in tests, so they know whether the programme is working.

Same scoping rules as the attendance report: by contract, breakable down by sub-group, and no observability of another organisation's data.

**Blocked by:** 26 - Roster sub-groups

**Status:** ready-for-agent

- [ ] A corporate admin sees test results for their own students only
- [ ] The report can be broken down by sub-group
- [ ] A request for another organisation's data is indistinguishable from a request for something that does not exist
- [ ] The report reflects the merged quiz engine's existing scoring, and introduces no new analysis
