# 06 - Question bank search and filter

**What to build:** Instructors can search the bank by text and filter by subject, topic, sub-topic, difficulty, question type, author and retired state.

The point is that a good question is found rather than rewritten.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Filtering by topic returns only questions tagged to that topic or its sub-topics
- [ ] Retired questions are excluded by default and included on request
- [ ] Text search matches prompt content across block types
- [ ] Filters compose: topic and difficulty together narrow rather than widen
- [ ] Results are paginated and stable under a repeated request
