# 07 - Question performance for the author

**What to build:** An instructor can see how students have actually performed on a question — attempts, correct rate, mean time, and the distribution across options where it has them.

This is how a hard question is told apart from a badly written one.

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] The figures aggregate across every test the question appears in, not one
- [ ] The option distribution shows which wrong option is attracting answers
- [ ] Mean time comes from the captured per-question timing
- [ ] A question with no attempts reports zero rather than failing
- [ ] A student cannot read these figures
