# 11 - Written and image answer types

**What to build:** Two question types that cannot be scored automatically: a written long-form answer, and an uploaded photograph of handwritten working. Both flow into the grading workflow rather than being scored at submission.

Uploads go through the existing media pipeline.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] A written answer is stored and returned to the grader intact
- [ ] An image answer accepts several pages of working
- [ ] A test containing either type submits without a final score and reports itself as awaiting grading
- [ ] Objective questions in the same test are still scored immediately
- [ ] A student cannot see a mark for an ungraded answer
