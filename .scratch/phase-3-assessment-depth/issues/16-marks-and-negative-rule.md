# 16 - Per-question marks and negative marking rule

**What to build:** Marks and the negative-marking rule are properties of a question's placement in a test, not of the question itself, so that scoring matches the exam being prepared for.

**Blocked by:** 14

**Status:** ready-for-agent

- [ ] Marks are set per placement and the same bank question carries different marks in two tests
- [ ] A negative rule is expressible per placement and falls back to the test default
- [ ] The test reports its own maximum score as the sum of its placements
- [ ] Changing marks on a test does not change the score of an attempt already submitted
- [ ] Marks cannot be zero or negative
