# 18 - Personal daily practice set

**What to build:** A short practice set generated per student each day, drawn from the topics their cohort is currently covering and weighted toward the topics they are weak in.

Personal per student is the whole point; a shared set cannot be weighted to anyone.

**Blocked by:** 17, 36

**Status:** ready-for-agent

- [ ] Two students in the same batch can receive different sets on the same day
- [ ] The set is drawn from topics the batch is currently covering
- [ ] A student weak in a topic receives more of it than a student who is not
- [ ] Requesting today's set twice returns the same set, not a new one
- [ ] A student with no attempt history still receives a set
