# 20 - Attempting the new question types

**What to build:** The attempt surface accepts an answer for every question type: single-correct, multiple-correct, numeric, written and uploaded image, alongside passage groups.

**Blocked by:** 09, 10, 11, 15

**Status:** ready-for-agent

- [ ] Each type accepts a well-formed answer and rejects one shaped for a different type
- [ ] A passage group presents its stimulus once and its members in order
- [ ] Answers can be saved and revised before submission
- [ ] Submitting twice is refused rather than creating a second attempt record
- [ ] An answer submitted after the attempt expires is refused
