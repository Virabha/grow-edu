# 24 - Rubrics

**What to build:** A rubric is a set of weighted criteria with a scale. Grading records a value per criterion, not only a total, so feedback is specific and a regrade can address one criterion.

**Blocked by:** 11

**Status:** ready-for-agent

- [ ] A rubric is authored independently and attached to a question placement
- [ ] The rubric total is the weighted sum of its criteria and cannot exceed the placement's marks
- [ ] A criterion value outside the scale is refused
- [ ] Editing a rubric does not change grades already recorded against it
- [ ] A question with no rubric can still be graded with a bare total
