# 27 - Photographed working in the grader

**What to build:** An image answer is presented to the grader alongside the rubric, so an instructor grades what the student actually did.

**Blocked by:** 26

**Status:** ready-for-agent

- [ ] Every uploaded page is retrievable by the grader in submission order
- [ ] The grader receives the rubric with the images in one read
- [ ] An image answer grades through exactly the same path as a written one
- [ ] A student cannot read another student's uploaded working
- [ ] An attempt with no upload for an image question grades as zero rather than blocking the queue
