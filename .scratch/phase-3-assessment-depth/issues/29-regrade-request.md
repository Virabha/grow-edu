# 29 - Regrade request

**What to build:** A student can request a regrade on a graded answer with their reasoning, and it arrives in a queue rather than in an email argument.

**Blocked by:** 26

**Status:** ready-for-agent

- [ ] A request carries the student's reason and names the specific answer
- [ ] A request against an ungraded answer is refused
- [ ] A student cannot open two open requests against the same answer
- [ ] Requests appear in an instructor queue scoped to their batches
- [ ] A request window can be closed and a late request is refused
