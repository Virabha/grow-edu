# 06 - Search inside a lecture

**What to build:** A student searches within a lecture and gets back the matching moments, so finding one explanation in a two-hour recording takes seconds.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] A search returns matching segments with their timestamps
- [ ] Matches are ordered by position in the lecture, not by relevance score
- [ ] Search is case-insensitive and matches across a segment boundary where the phrase spans one
- [ ] A search with no matches returns empty rather than failing
- [ ] A student cannot search a lecture they cannot access
