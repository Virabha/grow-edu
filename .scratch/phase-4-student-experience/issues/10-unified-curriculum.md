# 10 - One curriculum per batch

**What to build:** Everything for a batch — video, notes, live sessions, tests — in one ordered curriculum, so a student is not moving between separate lists.

**Blocked by:** 01, 09

**Status:** ready-for-agent

- [ ] A test appears in the curriculum without being duplicated as a lesson
- [ ] Drip and access rules are applied per item by the existing access module
- [ ] Reordering is explicit and stable
