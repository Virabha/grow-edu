# 11 - Per-lesson private notes and export

**What to build:** A student takes notes against a lesson, so notes live with the thing they are about. Notes are private to the student, and they can export them.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] A note attaches to a lesson and is readable only by its author
- [ ] An instructor or admin cannot read a student's notes through any interface
- [ ] Notes are editable and the edit does not create a second note
- [ ] Export returns every note for a batch in one document
- [ ] Notes survive the lesson being updated
