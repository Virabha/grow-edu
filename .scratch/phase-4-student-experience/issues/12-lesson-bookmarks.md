# 12 - Lesson bookmarks

**What to build:** A student bookmarks any lesson to build their own revision list, distinct from the timestamped video bookmarks in ticket 04.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Any lesson type can be bookmarked
- [ ] The list is per student and returns in recency order
- [ ] Bookmarking twice does not create a duplicate
- [ ] A bookmark to a lesson the student loses access to stops appearing
- [ ] Removing a bookmark leaves the lesson untouched
