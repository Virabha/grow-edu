# 16 - One daily review queue

**What to build:** A single daily queue combining spaced-repetition items and the day's practice set — not two competing daily obligations.

A student presented with two separate daily duties completes neither.

**Blocked by:** 15

**Status:** ready-for-agent

- [ ] The queue returns due review items and the day's practice set as one ordered list
- [ ] Requesting it twice on the same day returns the same queue
- [ ] Completing an item removes it from today's queue
- [ ] A student with nothing due still receives the practice set
- [ ] A student with no batch still receives their due review items
