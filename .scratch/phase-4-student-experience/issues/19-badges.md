# 19 - Badges for milestones

**What to build:** Badges awarded for milestones, so progress is visible beyond a percentage.

**Blocked by:** 17, 18

**Status:** ready-for-agent

- [ ] A badge is awarded exactly once when its criterion is met
- [ ] Re-evaluating does not award a second copy
- [ ] Badge criteria are owner-managed configuration, not literals in code
- [ ] A student sees their earned badges and the ones still available
- [ ] Awarding is recorded with the time it happened, from the injected clock
