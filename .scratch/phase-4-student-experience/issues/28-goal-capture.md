# 28 - Goal capture

**What to build:** A student states their goal at sign-up, and can edit it afterwards. Goal is the hook everything personal hangs from — recommendations, daily practice topic selection, and the catalogue's default filter.

**Blocked by:** 24

**Status:** ready-for-agent

- [ ] A goal is captured at sign-up and stored against the account
- [ ] It is editable afterwards and the change takes effect immediately
- [ ] The goal set is owner-managed configuration, not a hardcoded list
- [ ] The catalogue defaults to the student's goal when they are signed in
- [ ] A student without a goal still gets an unfiltered catalogue rather than an empty one
