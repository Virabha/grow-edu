# 29 - Diagnostic placement test

**What to build:** An ordinary test assembled from the question bank BY CRITERIA, distinguished only by what is done with the result: it produces a LEVEL and a RECOMMENDATION rather than a score and a rank.

**Blocked by:** 28

**Status:** ready-for-agent

- [ ] The test is assembled by the existing Phase 3 criteria generation, not a new mechanism
- [ ] Submitting produces a level, not a leaderboard position
- [ ] The level is stored against the account and drives recommendations
- [ ] A student sees their level and what it means, not a raw mark
- [ ] Retaking replaces the level rather than appending a second one
