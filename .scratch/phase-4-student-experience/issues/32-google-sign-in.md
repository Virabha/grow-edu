# 32 - Google sign-in

**What to build:** Sign-in with Google, so signing up takes one tap.

**Blocked by:** None - can start immediately

**Status:** ready-for-agent

- [ ] A verified Google identity signs the user in
- [ ] An unverified or forged token is refused
- [ ] A first-time Google sign-in creates an account carrying the verified email
- [ ] The provider is behind an injected port so tests can drive it without a live Google
- [ ] Sign-in failures never reveal whether an account exists
