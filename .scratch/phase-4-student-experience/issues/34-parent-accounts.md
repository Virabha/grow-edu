# 34 - Parent accounts

**What to build:** A parent account is a DISTINCT ACCOUNT with a link to a student, carrying read access to progress, attendance and results, and **no content access whatsoever**. It is not a role on the student's account and it does not consume a seat.

This item carries safeguarding weight and involves minors. The conservative position is deliberate.

**Blocked by:** None - can start immediately

**Status:** ready-for-agent

- [ ] A parent account links to a student and reads their progress, attendance and results
- [ ] A parent reaching for content receives the same response as for a non-existent record
- [ ] Linking requires the student's consent, not merely the parent's assertion
- [ ] A parent does not consume a seat on any contract
- [ ] A parent cannot see another student, including a sibling they are not linked to
