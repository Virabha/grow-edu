# 03 - The coding problem

**What to build:** A coding problem with a statement, constraints and worked examples, tagged by topic and difficulty.

**A problem is independent of any batch or path**, exactly as a question is independent of any test — the same decision made in Phase 3, for the same reasons. **Coding problems are NOT questions.** Do not force them into the question bank; their authoring, execution and verdict semantics share almost nothing with a multiple-choice question.

**Blocked by:** None - can start immediately

**Status:** ready-for-agent

- [ ] A problem carries a statement, constraints and examples, and reads back unchanged
- [ ] Problems are tagged by topic and difficulty and are reusable across paths
- [ ] A problem belongs to no batch and no path
- [ ] Statement content reuses the Phase 3 content-block format rather than a second one
- [ ] A student cannot author or edit a problem
