# 08 - Submitting for judgement

**What to build:** A student submits for judgement against the hidden cases, so that a solution is properly tested rather than fitted to the examples.

**Blocked by:** 04, 07

**Status:** ready-for-agent

- [ ] A submission is queued and never executed inline with the request
- [ ] The verdict is decided by the hidden cases
- [ ] A result attaches to the correct submission and a duplicate result is idempotent
- [ ] The student is notified when the verdict arrives
- [ ] A submission records the code submitted alongside its verdict
