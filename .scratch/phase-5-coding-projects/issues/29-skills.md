# 29 - Skills and demonstration

**What to build:** A skill taxonomy, owner-managed as every other taxonomy is, with items tagged by the skills they demonstrate. A skill is credited when a student completes tagged items at a defined threshold.

Progress becomes capability rather than content consumed.

**Blocked by:** 26

**Status:** done
**Covered by:** test/skills.int-spec.ts

- [x] Problems, projects and stages can be tagged with the skills they demonstrate
- [x] A skill is credited only at its defined threshold, never before
- [x] A student sees which skills they have demonstrated and which remain
